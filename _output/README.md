# _output/

Finished pages land here, one per run, in a `<slug>/` subfolder named for the site being built
(e.g. `_output/jonah-wang-sofas/`), containing `index.html` and an `assets/` folder for any
local images/videos it uses (copied in from `_input/images/` or `_input/videos/`, or generated).

This folder is scratch space for the current run — copy a finished `<slug>/` folder out to
wherever it actually needs to be deployed or handed off. It's safe to delete a `<slug>/`
subfolder once you've done that.
